MedMart - Frontend Development Task:

MedMart is a fully responsive frontend application developed based on the provided Figma design. The objective of this project is to accurately recreate the UI with clean, scalable, and performance‑optimized code using modern frontend development best practices.

This project demonstrates:

* Pixel‑perfect implementation of the provided Figma design.
* Fully responsive layouts across desktop, tablet, and mobile.
* Reusable components, consistent spacing, colors, and typography.
* Clean, semantic, and accessible HTML structure.
* Organized CSS and project structure for maintainability.


Technologies Used:

* HTML5 – Semantic and structured layout.
* CSS3 / SASS (SCSS) – Modular, scalable styling.
* Bootstrap 5 – Grid system, responsiveness, utilities.
* JavaScript (ES6) – DOM interactions, accordion control, event handling.
* jQuery – Used for UI interactions, responsive logic, and plugins.
* AOS – Scroll animations.
* Owl Carousel – Slider functionalities.

Setup Instructions (Run Locally):

Follow the steps below to run the project locally:

1. Clone the repository
https://github.com/Pooranalinagm/medmart.git

2. Navigate into the project folder

Development Practices Followed

* Used clean and semantic HTML.

* CSS is organized and easy to maintain.

* Common elements like buttons and cards are reused.

* Designed using a mobile-first responsive approach.

* Code is lightweight for better performance.



Assumptions & Limitations:

* This is a frontend-only project (no backend or API).

* Placeholder text and images are used where real content was not provided.

* Some animations and hover effects are basic versions of the Figma design.

* Tested mainly on the latest Chrome browser.
